## 挑海外VPS，真正决定体验的是这几样

价格表只是结果，用起来舒不舒服取决于线路、机房和虚拟化技术。看懂这三样，任何榜单里的推荐你都能自己判断值不值。

### 线路：国内访问速度的关键

国内用户访问海外服务器，回程线路基本决定了速度下限。常见线路的档次大致是：CN2 GIA > AS9929 > AS4837 > CN2 GT，再往下就是普通国际线路。不过这个排名不是死的，同一条线路，电信和联通用户的实际体验可能差别很大，最终要看你的本地网络。

花钱逻辑很简单：CN2 GIA和AS9929买的是晚高峰不掉速，普通线路省下的钱对应的是速度波动。给国内用户做网站，线路预算别省；自己用、跑后台任务，普通线路完全够。

### 机房位置：越近延迟越低，但越贵

延迟排序基本跟着物理距离走：国内机房最好，其次是中国大陆周边的香港、台湾、日本、韩国、新加坡，再远就是美国、欧洲。代价也很直接——香港机房的CN2 GIA方案（比如DMIT，39.9美元/月）比美国普通线路贵出好几倍。距离和价格，总得换一头。

### 虚拟化技术：优先KVM

虚拟化技术建议按KVM > Xen > OpenVZ的顺序挑，这个排序通常也是价格从高到低的排序。看到特别便宜但没写虚拟化类型的套餐，先问清楚再下单，OpenVZ便宜，限制也多。

### 下单前，先用Looking Glass测一遍

大部分正经商家都提供looking glass测试页，能测机房到你所在位置的真实延迟。这一步免费，两分钟就能做完，比看任何测评都直观。

## 常见问题

**海外VPS需要备案吗？**

不需要。备案只针对放在国内的服务器，海外主机买完就能直接托管网站。这也是香港和美国机房用得多的原因之一：访问速度快，还省去备案流程。

**10美元一年的VPS能干什么？**

这个价位的定位是轻量用途：个人博客、爬虫和定时脚本、监控、学习Linux运维都没问题。具体配置在下单页面上写得清清楚楚，下单前看一眼再决定。要跑高负载应用的话，这个预算撑不住，老老实实加钱。

**VPS和虚拟主机有什么区别？**

虚拟主机是把一台服务器分成很多份共享着卖，基本只能托管网站，价格便宜但性能有限；VPS是把CPU、内存、存储完整分隔，每台有独立IP，可以当一台独立服务器用，除了建站还能跑各种服务。要灵活性和性能选VPS，只放个简单网站的话虚拟主机更省事。

**美国VPS和香港VPS怎么选？**

看你为谁服务。给国内用户访问、在意速度，选香港CN2 GIA，预算参考DMIT的39.9美元/月；自己用、追求性价比，选美国，美西机房的延迟明显好于美东。预算卡在中间的，可以考虑走优化线路的美国机房，比如HostDare的CN2 GIA方案，年付50美元。
